# StudyQuest 無料βの公開案内原稿

STEP 04の**確認用原稿**。正式な提供条件ではない。運営者名称・問い合わせ受信・配置先・Privacy/Termsを確認し、無料βゲートと公開承認が揃ってからWebへ反映する。

## 利用者向け原稿

StudyQuestは、小さなクエストを選んで学習し、時間と達成を振り返る学習支援サービスです。無料βでは、クエスト一覧・受注・マイクエスト・学習タイマー・学習記録・週間状況・達成とXPを提供する予定です。

利用料は0円です。AIクエスト生成、AI計画・再計画、Plus、決済は提供していません。Googleログインは設定・確認が完了するまでは準備中です。架空の実績や未接続の操作を利用可能として案内しません。

タイマー終了後に分数とメモを確認して保存します。保存失敗時は同じ画面で再試行できます。ログイン期限切れの場合は別タブで同じアカウントへ再ログインし、元の画面で再試行してください。画面を閉じたり移動したりすると未保存の時間・入力は失われます。

βは少人数での試行です。障害や無料枠の上限により一時停止する場合があります。運営が費用を支出する有料プランへの自動移行は予定していません。提供・停止条件の正式な案内は公開前に確定します。

運営者: **表示名称を確認待ち**（開発チーム: GtoWell）

お問い合わせ: **`info@gtowell.dev`を予定、受信・返信確認待ち**。不具合の際は操作内容と発生時刻をお知らせください。パスワードや認証リンクは送らないでください。

## 個人情報の説明に含める内容

| 内容 | 技術上の事実・公開前の残件 |
| --- | --- |
| アカウント | 表示名・メール・確認状態、パスワードhash、認証情報をPostgreSQLに保存 |
| 学習 | クエスト進行、日時・分数・任意メモ、XP/points、活動ログを保存 |
| Cookie | HttpOnlyのDB session Cookie。本番Secureの設定は実HTTPSで確認待ち |
| 利用目的 | 本人確認、学習機能、本人の週間状況、不正利用防止、問い合わせ対応 |
| 外部委託 | 配置・DB・認証メールの事業者は候補。選定後に送信範囲・地域・保持と削除を確認 |
| 漏洩確認 | Better Authのパスワード漏洩確認プラグインを使用。外部照会の送信内容・保持条件は確認待ち |
| Google | 準備中。提供開始時に基本プロフィール・アカウント連携を説明 |
| β計測 | 登録・初回受注・初回保存・7日再利用を集計。イベントへメール・学習メモを含めない |
| 掲示板 | 表示名と受注/達成が他のログイン利用者に見える。βでの提供判断・説明は確認待ち |
| 保持・削除 | DB/バックアップ/委託先の保持期間、削除依頼と対応手順は運営者確認待ち。セルフ退会は未実装 |

この原稿で正式なPrivacy Policy・利用規約が完成したとは扱わない。`/privacy`と`/terms`は技術ドラフト。現在の画面と`.env.example`の`admin@gtowell.dev`は旧案で、`info@`の動作確認後に公開版タスクで揃える。
